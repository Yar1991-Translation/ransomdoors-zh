# RANS0M

[English](README.md) | 简体中文

> **非官方简体中文汉化版。** 本项目是 [Ixars/ransomdoors](https://github.com/Ixars/ransomdoors) 的汉化分支，由 **Yatmt** 翻译维护，原项目及其全部素材归 **Ixar** 所有。除界面文案与文档外，程序逻辑未做改动；按原许可证（[LICENSE.md](LICENSE.md)）要求，此处声明本次修改内容：程序内可读文案的本地化、新增中文说明文档、新增编译校验工作流。

这是 Roblox 游戏《Doors》中 RANSOM（A-90）实体的同人复刻程序，做成 Windows 桌面应用的形式。它会随机把实体那张脸弹到你屏幕上，这时你得停下鼠标、别碰键盘，否则它就会“感染”你的电脑：金币文件（面值不同，扩展名 `.gold1`~`.gold6`）会被散落到你的用户文件夹里，光标会变样，壁纸也会变成暗红色。你需要在倒计时结束前，把足够多的金币拖到赎金窗口上，筹够设定好的赎金金额。另外还有一种稀有的 `.crucifix` 文件，找到它并拖进去就能立刻清空赎金。

这东西纯粹是做着玩的，代码写得也就那样。
目前唯一比较明显的 bug 是赎金窗口不总能压在其他窗口上面，但大体上没问题；它没法覆盖全屏应用。

## 运行前必读

默认情况下，超时没付钱只是把一切复原（不会崩溃，也不会执行命令）。但**如果你自己在配置窗口里打开对应开关**，这个程序**确实会**关机、让电脑崩溃，或者执行任意 shell 命令——这些选项都是自愿开启，默认关闭。开启“失败时关机”会调用 `shutdown /s /t 0`；开启“失败时执行自定义命令”会执行你填进去的那条命令。所以：

- 请只在你自己拥有的电脑上运行；如果你打开了关机或自定义命令选项，先保存好手头的工作，并且做好它真的会执行的心理准备。
- 不要在对方不了解其具体行为、也没有同意的情况下，把它运行在别人的电脑上。

它不属于恶意软件：不窃取任何东西，不隐藏自己，也不传播；除了丢下和删除自己那些无害的 `.gold`/`.crucifix` 标记文件之外，不会碰你的其他文件。而且它完全开源，你可以自己核对。完整条款与免责声明见 [LICENSE.md](LICENSE.md)。

## 系统要求

- Windows（用到 Win32 钩子、`shutdown.exe`、注册表等，换别的系统跑不起来）
- [.NET 10 SDK](https://dotnet.microsoft.com/) 或更新版本
- Visual Studio 2022+（可选，用于 WinForms 设计器），或者直接用 `dotnet` 命令行

## 构建与运行

```
git clone https://github.com/Yar1991-Translation/ransomdoors-zh
cd ransomdoors-zh
dotnet build
dotnet run
```

或者用 Visual Studio 打开 `rans0m.slnx`，按 F5 运行。

程序以系统托盘图标的形式运行。右键它可以看到：
- **配置**
- **退出**

## 配置

所有设置都在**配置**窗口里管理（托盘图标 → 配置），并保存在可执行文件旁边的 `config.json` 中：

- **自动出现** —— 实体是否按计时器自己冒出来。
- **最短间隔 / 最长间隔** —— 它随机出现的间隔范围（秒）。
- **赎金时限** —— 一旦被感染，你有多少秒付清赎金。
- **赎金金额** —— 你需要筹够多少金币才能付清。
- **金币生成位置** —— 是散落到你自己的桌面／文档／图片／音乐／视频／下载文件夹，还是散落进一个临时目录树（“抽屉”）里。
- **失败时关机** —— 超时没付钱就执行 `shutdown /s /t 0`。默认关闭。
- **失败时执行自定义命令** —— 超时没付钱就执行你填写的 shell 命令。默认关闭。

你也可以在这个窗口里立刻触发一次赎金，用来测试你的设置。

图片、音效以及弹窗标题存放在 `Properties/Resources.resx` 和 `Resources/`、`Assets/` 目录中，想替换随时可以换。
